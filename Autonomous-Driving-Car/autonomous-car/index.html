    Autonomous Driving Vehicle

    • Being update!!! ...

    1. Introduction

    Welcome to the documentation of my Autonomous Driving Vehicle project developed for the Bosch Future Mobility Challenge (BFMC).
    This project is a 1:10 scale autonomous car platform designed to perform real-world driving tasks such as traffic signs perception, lane keeping, obstacle avoidance, intersection handling, and autonomous parking.

    2. Objectives

    • Compete in the BFMC competition.
    • Develop a robust autonomous driving stack combining perception, planning, and control based on Sensors (Camera, Distance Sensor) and Actuators (BLDC Motor and Servo).
    • Integrate embedded hardware (STM32F401RE Nucleo, Jetson Xavier NX) with ROS.
    • Demonstrate safe and reliable driving behavior in a constrained track environment.
    • The vehicle should be able to perform the challenges:
      • Lane keeping
      • Follow the traffic rules detected from traffic signs
      • Obstacle avoidance (Pedestrians and Other Vehicles on road)
      • Intersection handling
      • Autonomous parking
      • Complete the planned path by localization and navigation

    3. Hardware

    3.1 Computing Units

    • NVIDIA Jetson Xavier NX
      • Runs Ubuntu + ROS
      • Handle sensor input (fusion), AI inference, perception and decision making (motion planning and control command)
    • STM32F401RE
      • Runs Mbed OS
      • Handles low-level motor and steering control (from received control command)
      • Interfaces with sensors (IMU, encoder, ultrasonic) and input to the Single Board Computer (Jetson Xavier NX)

    3.2 Sensors

    Sensor Purpose
    Camera (Logitech C922) Lane detection, sign detection
    IMU Vehicle orientation and angular velocity
    Encoder Wheel angular velocity estimation
    V2X Position estimation
    Ultrasonic sensor Obstacle distance

    3.3 Actuators

    • BLDC motor + ESC (longitudinal control)
    • Servo motor (steering, Ackermann geometry)

    4. System Architecture

    The system is divided into the following modules:

    4.1. Perception

    • Lane detection (camera-based, DBSCANS).
    • Obstacle detection (ultrasonic sensors and Yolov8 Object detection).
    • Signs & traffic light recognition (Yolov8 Object detection).

    4.2. Planning

    • Behavior planner (FSM-based).
    • Global/local path generation (Dijkstra search for global path and static path for local path).
    • Obstacle avoidance & lane switching.

    4.3. Actuator Control

    • Low-level motor + steering control (PID & Stanley).
    • Safety overrides & emergency stop (Cruise control).

    6. Perception

    6.1 Overview

    The Perception module provides real-time environmental understanding for the autonomous vehicle. Its primary functions include lane detection, object and traffic sign recognition, traffic light state estimation, and intersection detection. The output of this module supplies structured information to the planning and control layers through ROS topics.

    6.2 Input and Pre-processing

    A forward-facing RGB camera is used as the primary perception sensor. Captured frames are pre-processed using grayscale conversion, Gaussian filtering, and edge enhancement to improve robustness against noise and illumination variation.

    6.3 Lane Detection Methodology

    Lane detection is implemented using a classical computer vision pipeline combined with clustering:

    • Edge extraction is performed using Sobel and Canny operators.
    • Line candidates are extracted using the Hough Transform.
    • DBSCAN clustering groups fragmented lane segments and removes noise.
    • Left and right lane boundaries are identified, and the lane center is computed as the midpoint.

    The method supports both solid and dashed lane markings and provides a stable middle-point reference for lateral control.

    6.4 Illumination Handling

    To reduce the impact of glare and uneven lighting, histogram-based intensity correction is applied during pre-processing. This step improves the reliability of both lane detection and object recognition under challenging lighting conditions.

    6.5 Object and Traffic Sign Detection

    Object detection is performed using a YOLOv8 deep learning model fine-tuned on a custom dataset. Detected objects include traffic signs, vehicles, pedestrians, traffic lights, and intersections.

    To improve classification accuracy for traffic signs, a lightweight secondary classifier is applied to verify YOLO detections.

    6.6 Traffic Light Recognition

    Traffic light states are determined either directly through the detection model or via image-based color analysis within detected traffic light regions. This hybrid approach ensures robust recognition while maintaining real-time performance.

    6.7 Intersection Detection

    Intersections are detected by combining visual features from the perception pipeline with vehicle localization data. This information is used to determine feasible maneuvers and is forwarded to the planning module.

    6.8 ROS-Based Integration

    The perception system is implemented as a set of ROS nodes, each responsible for a specific task such as image acquisition, lane detection, or object recognition. Communication between nodes is handled through standard ROS topics, enabling modularity and scalability.

    6.9 Summary

    The perception module integrates classical vision techniques and deep learning to deliver reliable lane, object, and intersection information. Its modular ROS-based design allows real-time operation and seamless integration with planning and control components.
